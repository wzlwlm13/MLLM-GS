# MLLM-GS Project Page

Project page for:

**MLLM-GS: Multimodal Large Language Model Prior-Guided Fast Novel View Synthesis in Extreme Environments**

Zhiliang Wu, Xinye Zheng, Kun Li, Fei Wang, Hao Guo, Yanyan Wei, Guanghui Yue, Beier Zhu, Wei Zhou, Xun Yang

The page is adapted from the Nerfies GitHub Pages template and includes:

- teaser and abstract;
- framework overview (MLLM prior-guided view enhancement + fast 3D scene reconstruction);

- visual comparisons under smoke, low light, defocus blur, motion blur, and varying exposure;
- conclusion and BibTeX.
